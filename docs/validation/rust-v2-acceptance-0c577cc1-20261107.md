## Generated release benchmarks

20 connections, a four-wide pipeline and three timed repetitions. No Rust
compiler was active during measurement. The host was shared; this is neither
a production speed estimate nor a fresh comparison against C#.

| Scenario | Observed result |
| --- | --- |
| Cold ramp | 76.782 MB/s; 480.0 ms to 8 MB |
| Cold ramp with connection prewarming | 76.716 MB/s; 480.3 ms to 8 MB |
| Open-ended 8 MB seeks | First byte median 288 ms, maximum 345 ms; read median 356 ms |
| Bounded 8 MB seeks | First byte median 110 ms, maximum 166 ms; read median 178 ms |

Both cold correctness reads matched all 268,959,744 expected bytes. The seek
harness reports timing; byte correctness is separately covered by the native
POCs and release-image range checks. No improvement percentage is inferred.
